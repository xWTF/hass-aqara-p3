# Aqara brand images

[Home Assistant brands repository](https://github.com/home-assistant/brands/tree/master/core_brands/aqara).

The images and trademarks belong to their respective rights holders; the project's
GPL-3.0-only declaration for its own code does not relicense these brand assets.

Home Assistant serves this directory locally for the `aqara_p3` integration,
including the dark-theme and high-resolution variants.
