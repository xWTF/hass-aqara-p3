## 边界

历史实机验证包含这份 rootfs 与相同内核负载的重启、Telnet 自启及 HA 功能。此次公共双分区安装流程及 4.0.1 直接升级仅做了离线验证；没有新增刷机或断电测试。

上述测试不覆盖真实 NAND 擦除/坏块、OOB/ECC、掉电、DRAM/无线初始化或完整 Linux 启动。通过兼容检查是进入安装流程的条件，不是无条件的硬件成功保证。

复现入口见项目 skill 的 `scripts/test_public_bundle.py` 和 `scripts/test_boot_policy.py --paired-bundle`。测试报告、模拟磁盘和设备专属输入留在操作者私有目录。
